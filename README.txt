RAJ ENTERPRISES — Store Management System

1. Open this folder in VS Code and run login.html with Live Server.
2. Only one frontend demo admin is supported: Jatin Arora.
3. In login.html change ADMIN_EMAIL and ADMIN_PASSWORD to your chosen values.
   Default email: jatin@gmail.com; default password: jatin123.
4. No Create Account option. Forgot password opens an email draft, NOT a reset link.
5. Products: add individually or use Bulk add / CSV import.
6. Reports: charts, sales summaries, expenses.
7. All data is stored in browser localStorage. Back up before clearing browser storage.
8. This is frontend-only and credentials in source code are NOT secure for real deployment.

IMPORTANT: Use the entire extracted folder, with original filenames.
